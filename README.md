# BlenderScripts
Collection of Helper Scripts in Blender. Each has a unique Readme. AI Usage clarified per script.

Repository is on GPL 3.0 because Blender is GPL'd and this library imports Blender's library.

Existing Scripts:
* `duplicate_for_substance.py` - Script takes a given root armature and replicates it several times, making various shapekey and bone changes. Made to simplify Substance Painter-ready fbx export.
